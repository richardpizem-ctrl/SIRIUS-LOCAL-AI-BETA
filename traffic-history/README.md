# 📊 SIRIUS Traffic History

Tento priečinok obsahuje dlhodobú históriu klonov a návštev projektu SIRIUS-LOCAL-AI-BETA.

GitHub štandardne uchováva traffic iba 14 dní.  
Preto si SIRIUS ukladá vlastnú históriu, aby bolo možné sledovať:

- počet klonov
- počet unikátnych klonerov
- počet návštev
- počet unikátnych návštevníkov
- dlhodobé trendy
- reálny záujem o projekt

Denné dáta sú uložené v JSON súboroch:
traffic-history/
2026-08-26.json
2026-08-27.json
...

Každý deň pribudne nový súbor s aktuálnymi hodnotami.
