## ✔ 5.9.1 UNIFIED — Dual-Language KG, Native Merge, Ontological Reasoning & COLNÍK Guard (Current Milestone)  
- **Dual-Language Isolated Knowledge Stores:** Physical and logical partition across Slovak (`autosave_kg.json`) and English (`autosave_kg_en.json`) with dynamic language context switching based on UI header  
- **Native Lossless KG Merge Engine (`kg merge <src> into <tgt>`):** Direct runtime consolidation relocating all properties, summaries, and habitat records from source to target with directional alias linking (`src -[alias]-> tgt`)  
- **Ontological & Taxonomical Category Deduction (`KG_VERIFY`):** Deduces higher-order biological categories directly from stored records (marsupials -> mammals) with persistent edge auto-commits  
- **Non-Destructive Reverse Location Engine (`_execute_reverse_location_query`):** Multi-stem regional search (*Austrálii*, *Austrália*, *Australia*) with False-Positive Flora Guard and standardized `get_attributes()` traversal  
- **Entry-Level Token Guard:** Immediate input-level rejection of malformed or dangerous symbolic injection sequences (`@#$%^&*`)  
- **Greedy Trailing Punctuation Stripping (`.rstrip("?")`):** Guarantees exact node lookups without trailing question mark fragmentation  
- **Confirmation State Latching:** Deterministic state preservation across interactive conversation turns, preventing dropped confirmation context  
- **COLNÍK Guard Shell Interceptor (`TerminalAssistant`):** 0.0s hard blocking of forbidden commands (`format`, `diskpart`, `rmdir /s`, `del /f /s /q c:`, `drop database`), prompt checks for risky commands, and latency profiling via TimeCore `cycle_delta()`  
- **Human-in-the-Loop (HitL) Safe UI Trash:** Direct unverified disk deletions are blocked; file removals route into quarantine awaiting manual approval via `GET /trash`  
- **Sliding-Window Quarantine Rotation (`EnvoyQuarantine5`):** Automatic pruning enforcing a strict 100-file ceiling inside `COLNIK-6.x/envoy/quarantine/`  
- **Multi-Stage Character Encoding Fallback:** UTF-8 -> CP1250 -> CP852 pipeline guaranteeing diacritics integrity  
- **Embedded Single-Process Daemons:** Single-process integration on port 8080 embedding TerminalAssistant and TimeCore directly into `sirius_orchestrator.py`
