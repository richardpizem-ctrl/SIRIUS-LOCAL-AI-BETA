Riadená autonómia

SIRIUS vykonáva autonómne akcie iba v rámci striktne definovaných pravidiel.

  • Žiadne akcie mimo modulov
  • Každá akcia je vysvetliteľná
  • Agenti majú pevné hranice
  • Žiadne pozadie, žiadne skryté procesy
Bezpečnostné vrstvy

Bezpečnosť je jadrom SIRIUS. Každá akcia je kontrolovaná.

  • COLNÍK – kontrola prístupov
  • ENVOY – karanténa
  • Family Security – ochrana rodiny
  • Strict capability boundaries
Knowledge Graph (KG)

KG je štruktúrovaný mozog SIRIUS.

  • Entity a vlastnosti
  • Relácie a dedukcie
  • EXPLAIN / WHY / PATH
  • Hlboké vysvetlenia
