03 / INTERNALS

System architecture

Explore the subsystems coordinated by the v6.0.1 runtime.

01Single-Process Orchestrator (sirius_orchestrator.py)

Central execution daemon hosting HTTP/WebSocket IPC natively on port 8080 with embedded TerminalAssistant and TimeCore latency profiling (cycle_delta()), eliminating file-locking bottlenecks.

02Dual-Language Isolated Knowledge Stores & Native Merge

Manages atomic dual-disk persistence across Slovak and English graphs. Features native in-memory entity consolidation (kg merge <src> into <tgt>) and taxonomical category deduction (KG_VERIFY).

03COLNÍK Guard & HitL Safe Trash

Enterprise-grade host protection intercepting destructive commands in 0.0s and routing file disposals into quarantine storage awaiting manual review via GET /trash.

04Professor Middleware Layer

Authoritative data quality gateway (PASS / WARN / REJECT) ensuring erroneous or contradictory facts never reach the UI presentation layer.

04 / GUARDRAILS

Safety & policy

  • Token Guard Sanitization: Immediate runtime rejection of malformed injection sequences (@#$%^&*).
  • Terminal State Decoupling: Clearing input immediately resets currentModule = "none", preventing natural language queries from capturing host OS shells.
  • Zero Proposal Recurrence: Once a concept, alias, or taxonomical edge is confirmed, it permanently bypasses repetitive learning prompts.
  • Sliding-Window Quarantine Rotation: Automated maintenance enforcing a strict 100-file ceiling inside COLNIK-6.x/envoy/quarantine/.
