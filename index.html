SIRIUS LOCAL AI

A deterministic, strictly offline AI runtime engineered for Windows 11. Designed from the ground up for predictable execution, modular isolation, and absolute control over local system actions without any background cloud dependency.

Core Principles

Privacy First

100% offline runtime. No telemetry, no background outbound sockets, and zero data leakage to external clouds.

Deterministic Engine

Every response and reasoning step is explainable, rule-bound, and strictly verifiable without generative hallucinations.

Controlled Autonomy

Zero unmonitored background executions. Modifying filesystem states requires explicit user policy confirmation.

Unified Knowledge Graph

Local semantic memory and relational reasoning engine (RRE) capable of multi-hop deductions and reverse queries.

Getting Started

SIRIUS operates efficiently on standard CPU architectures without dedicated GPU acceleration requirements.

System Architecture

The runtime enforces strict boundary separation across modular pipelines:

Runtime Core 5.x / 6.x

The centralized orchestration backbone. Handles semantic routing, input triage, reverse location lookups, and IPC dispatcher pipelines.

Knowledge Graph (KG) & Reasoning Engine (RRE)

Internal graph database storing entities, properties, and ontological hierarchies. Includes transitivity engines (`REASON INFER`), orbit validation, and explanation trees (`EXPLAIN / WHY / PATH`).

COLNÍK & Security Layer

Gatekeeper layer responsible for capability bounds, permission policies, quarantine verification, and family safety rules.

ENVOY Subsystem

Controlled external synchronizer and normalizer with automated token filtering, semantic extraction, and local cache backups.

Safety & Policy Standards

  • Strict Capability Boundaries: Modules cannot access unassigned memory or unpermitted filesystem trees.
  • Deterministic Behavior: Identical queries produce mathematically consistent deduction paths.
  • No Silent Automation: Any action modifying state requires interactive confirmation.
  • Offline Survivability: Operates autonomously in disconnected offline environments.
