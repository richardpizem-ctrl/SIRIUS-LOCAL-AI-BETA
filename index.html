Overview

SIRIUS LOCAL AI is a fully offline, deterministic AI runtime for Windows 11. It is designed for maximum security, predictable behavior, and complete control over system actions.

Why SIRIUS?

  • Privacy First: No network communication.
  • Deterministic Execution: No hidden processes.
  • Modular Architecture: Each module has strict boundaries.
  • Security Over Convenience: No destructive actions without confirmation.

Getting Started

SIRIUS runs locally without GPU requirements. Installation is simple:

  • Clone the repository.
  • Run the Python-based runtime.
  • Enable modules as needed.

Key Features

  • Offline operation
  • No background automation
  • Deterministic reasoning
  • Modular system design
  • Strict capability boundaries

Architecture

The SIRIUS architecture consists of multiple controlled modules:

  • Runtime 5.x / 6.x
  • COLNÍK – Security module
  • AUTONOMY – Controlled actions
  • KG – Knowledge Graph
  • ReasoningEngine – Deterministic reasoning
  • ENVOY – Quarantine layer
  • AMBASSADOR – System interface
  • Family Security – Protection layers
Controlled Autonomy

SIRIUS executes actions only inside strict rules.

  • No actions outside defined modules
  • Every action is explainable
  • No hidden background processes
  • Agents have strict boundaries
Security Layers
