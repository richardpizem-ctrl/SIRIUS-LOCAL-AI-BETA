# DELTA-MEDIC v1.3.1

**Offline demo in SIRIUS LOCAL AI BETA v6.1.0**

Open **DELTA-MEDIC (demo)** from the BETA menu. The panel includes five Slovak and four English sample records. English titles include Slovak translations in parentheses.

## Build your own catalogue

- Search by title or description, or filter by category.
- Use **Pridať uzol** or **Add Node** to add your own record. You can also edit or delete the sample records.
- Changes are stored locally in the panel’s browser storage.

## Import and export JSON

Use **Export JSON** to back up or share a catalogue. **Import replaces the entire catalogue for the selected language**, so export your existing records first if you want to keep them.

| Language | Filename for import |
| --- | --- |
| Slovak | `autosave_kg_delta.json` |
| English | `autosave_kg_en_delta.json` |

## Demo scope

Use DELTA-MEDIC for terminology, study notes, or fictional records. The demo displays the score stored in each record and shows links to related records. Patient charts and visit history are planned for **DELTA2 MEDIC**.

## Windows verification

The installed Windows Preview opened DELTA-MEDIC from the BETA menu and displayed all five Slovak and four English sample records.
